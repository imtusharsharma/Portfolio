FEATURED_PROJECT_01
MICROSOFT EXCEL · DATA ANALYSIS · DASHBOARD DEVELOPMENT

Cricket Player Performance Dashboard

An end-to-end Excel data analytics project where raw cricket performance data was transformed into a meaningful, interactive dashboard for identifying top performers and comparing player performance.

01. Raw Data to Analysis

Started with row-level cricket data and organized it for analysis. The data was cleaned and transformed so player and performance information could be used reliably for reporting and KPI calculation.

02. Functions & Techniques Used

Used advanced Excel techniques including XLOOKUP, INDEX-MATCH, IF and SUMIFS, along with data cleaning and transformation methods to prepare analysis-ready data.

03. Dashboard Development

Built the dashboard using Pivot Tables, Pivot Charts, Slicers and Conditional Formatting. Interactive filters allow users to explore and compare performance dynamically.

04. Performance Insights

Generated important KPIs such as Total Runs, Wickets, Strike Rate, Economy Rate, Centuries, Fifties and 5-Wicket Hauls to highlight leading players and performance patterns.

05. Top Performer Analysis

Designed a Top-N Players view that makes it easier to identify top performers, compare players in real time and turn detailed statistics into clear, actionable insights.

06. Final Outcome

Converted large amounts of raw performance data into a visually clear dashboard that supports faster analysis, automated reporting and data-driven understanding of cricket performance.
